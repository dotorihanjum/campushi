# 데이터 출처

## 학과·교육과정 (`data/departments.json`)

두 학과의 학년별 과목은 학교가 공개한 공식 교육과정 문서의 [별표1] 교육과정 편성표에서 이수학년 칸을 그대로 옮겼다(2026-11-03 확인).

| 학과 | 문서 | 주소 |
| --- | --- | --- |
| 경희대학교 소프트웨어융합대학 컴퓨터공학부 컴퓨터공학과 | 2026학년도 교육과정 [별표1] 교육과정 편성표 | https://ce.khu.ac.kr/ce25/cmmn/file/fileDown.do?menuNo=21600025&atchFileId=317a0f82d4104052bfa37b7865b6038a&fileSn=1&bbsId=BMSR00048 |
| 경희대학교 예술·디자인대학 산업디자인학과 | 2025 교육과정 [별표1] 교육과정 편성표, [별표7] 교육과정 이수체계도 | https://dc.khu.ac.kr/dc/cmmn/file/fileDown.do?menuNo=15400056&atchFileId=264fb13d9a0a4c17ba986b274cef66be&fileSn=1&bbsId= |

- 컴퓨터공학과: 이수학년이 범위(예: 3-4)인 과목은 시작 학년에 넣었다. 개설학기가 △로만 표시된 학기는 빼고 넣었다(△의 뜻이 문서에 없음). 원문 오타 `메타버스테이터처리`는 문서 그대로 두었다.
- 산업디자인학과: 문서의 이수학년 칸 그대로다.
- 학기마다 그 학년 편성표의 모든 과목(졸업 과제 과목 제외)을 고를 수 있다(2026-11-03 사용자 결정). 논문·연구연수활동·독립심화학습·몰입심화학습처럼 강의가 아닌 항목도 편성표에 있으므로 그대로 둔다.
- `practice`는 학과군 실습 체험을 붙인 과목, `final`은 4학년 2학기 졸업 과제 과목이다.

형식 (`departments` 배열의 항목):

| 필드 | 뜻 |
| --- | --- |
| `id`, `school`, `name`, `official_name` | 학과 식별자와 이름 |
| `group` | 학과군(`computing` 또는 `design`). 실습·졸업 과제 체험을 정한다 |
| `partner`, `partner_example` | 제휴 학교 여부와 예시 제휴 여부 |
| `source` | 교육과정 문서 제목, 주소, 적용 연도, 확인 날짜 |
| `years` | 학년(`"1"`~`"4"`) → 편성표의 과목 |
| `practice`, `final` | 실습 과목, 졸업 과제 과목 |

서버는 시작할 때 이 형식을 검사하고(`main.check_department`), 맞지 않으면 뜨지 않는다.
